About This Site

When I started learning software development, I only knew the front-end. My first portfolio was a static site hosted on GitHub Pages and was a pain to update and make additions to, so I rarely did. I wanted to ease that process so I could host and own a simple way to create, share, and update my project write-ups without relying on another platform. As my front-end web development knowledge grew into the back-end, database, and infrastructure layers, I became confident enough to build my own Content Management System (CMS).

The result is this site. Here, I write about and share my projects and the technologies behind them, what I've learned (and am still figuring out), my hobbies, and whatever else feels worth putting out there. I use it for self-reflection, personal project retrospectives, to help others avoid issues I've come across, and to carve out a quiet corner of the web for myself amid all the noise. Everything here is written in my own words and opinions, and there will never be any AI-generated content, ads, or tracking.

Welcome to my corner of the web!
